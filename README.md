# Euromontec Website

Website für die Euromontec Personalmanagement GmbH.
Gebaut mit React, Vite & Tailwind.

## Features

- Responsive design that works on all devices
- Clean, timeless aesthetic
- Hero section with clear value proposition
- Services showcase with 6 key offerings
- Benefits section highlighting advantages
- Call-to-action sections
- Professional footer

## Tech Stack

- React 18
- Tailwind CSS 3
- Vite (build tool)

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Run development server:
```bash
npm run dev
```

3. Build for production:
```bash
npm run build
```

## Design Philosophy

The design focuses on:
- Clean, professional aesthetics
- Clear information hierarchy
- Easy navigation
- Trust-building elements
- Conversion-focused CTAs

## Customization

- Colors can be adjusted in `tailwind.config.js`
- Content can be modified in individual component files
